## Cómo leer las etiquetas

- `[FUENTE: T1 p. N]`, `[FUENTE: T2 p. N]` y `[FUENTE: CA p. N]`: contenido transcrito o desarrollado desde el corpus Markdown página por página. Los PDF originales están disponibles y se renderizaron las 118 páginas. El alcance y las limitaciones de la inspección se detallan en el informe de validación.
- `[AMPLIACIÓN OFICIAL]`: contenido añadido desde documentación oficial AWS y la guía CLF-C02.
- `[EXPLICACIÓN EDITORIAL]`: aclaración pedagógica o definición añadida para hacer estudiable un servicio o concepto.

## Ruta de estudio sugerida

Lee primero los capítulos 1 y 2 para construir el vocabulario y entender el modelo económico; después estudia el capítulo 3, que conecta la infraestructura global con los principios arquitectónicos. Termina con el capítulo 4 para revisar la adopción empresarial y las estrategias de migración. Usa el glosario para repasar términos y la matriz para volver a las páginas fuente.

El dominio 1 representa el **24 % de las preguntas puntuables** del CLF-C02. Sus tareas 1.1–1.4 aparecen señaladas en los capítulos 1–4. El porcentaje corresponde al dominio completo y no se reparte oficialmente por capítulo.
