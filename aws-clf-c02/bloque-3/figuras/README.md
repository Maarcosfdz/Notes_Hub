# Figuras del Bloque III

236 reproducciones JPG conservadas byte a byte desde el paquete de preparación. Los nombres identifican fuente y página: `t5_p24.jpg` representa T5, página24. En T5–T9 se utiliza el índice físico del archivo, que puede diferir del número impreso por repeticiones o desfases. Las selecciones T1/T2 conservan su número original en el nombre.

La [matriz](../16_matriz_cobertura.md) enlaza cada una y distingue revisión visual general, ampliación individual, contenido administrativo y economía reservada para Bloque IV. El [corpus](../fuentes/05_CORPUS_POR_PAGINA.md) conserva también el texto recuperado por OCR y sus limitaciones.

Las figuras son páginas completas, no recortes certificados de diagramas. Se conservan anotaciones y marcas del material entregado. El manual reconstruye en tablas y explicaciones los elementos que utiliza; los detalles pequeños o mal reconocidos requieren consultar la imagen completa o el PDF original del proyecto.
